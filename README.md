## 🌐 Explore the Live Interactive Guide

Read and interact with the full wildlife architecture guide online:  
👉 **[lin4cre.github.io/bonny-bats](https://lin4cre.github.io/bonny-bats/)**

- **Live Seasonal Maternity Awareness:** Dynamic JavaScript clock that automatically computes current breeding season restrictions and warns when exclusion must wait to protect bat pups.
- **5-Step Humane Exclusion Process:** Detailed breakdown of survey, emergence monitoring, one-way exclusion valves, and permanent structural sealing.
- **Safe Guano Clean-Up Guide:** Homeowner safety protocols and HEPA filtration guidance.
- **One-Click Print Ready:** Formatted specifically for clean A4 printing for client handovers and survey reports.
- **Zero Dependencies:** Single self-contained HTML file running 100% offline.
